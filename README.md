# Pokedex Website

A web-based Pokedex application that allows users to browse and filter Pokemon by various attributes.

## Features

- Browse all Pokemon
- Filter by type, generation, and other attributes
- Detailed Pokemon information
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Grid Layout
- Flexbox

## Live Demo

The live demo of this project can be found at: `https://[your-username].github.io/pokedex-website/`

## Local Development

1. Clone the repository
2. Place your Pokemon data files in the `api` folder (not included in repository)
3. Open `index.html` in your browser

## Note

This project requires Pokemon data files that are not included in the repository. You'll need to provide your own data files in the correct format.
